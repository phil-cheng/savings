# 三罐储蓄

本机运行的轻量储蓄记账 Web 应用：一个页面 + 一个 Node 服务，数据落在本地 `data/data.json`，支持局域网多设备访问，并通过 Git 做远程备份。

## 功能概览

- **三个储蓄罐**：消费储蓄罐、爱心储蓄罐、超级存钱罐
- **分层水位**：每层 100 元，水位只反映当前层进度；支持升级 / 降级提示
- **快捷加减**：±5 / 10 / 20 / 30 / 50，以及自定义金额
- **操作日志**：可按「全部 / 消费罐 / 爱心罐 / 超级罐」筛选
- **每周记录**：周日 20:00（上海时区）自动结算快照；打开页面时也会补算  
  列包含：周次、消费、爱心、超级存钱罐、超级变动（比上周）、总额、总变动（比上周）、结算日期
- **储蓄政策**：页面内可查看大额奖励、月累计奖励、超级罐周结福利说明
- **多端安全**：加减前先从服务端同步最新数据，降低旧页面覆盖新数据的风险
- **修改保护**：改金额需验证密码（初始 `family`）；改密必须先验证旧密码；密码以哈希写入 `data.json`
- **远程备份**：`npm run backup` 提交并推送 `data/data.json`

## 技术结构

```text
savings/
├── server.js              # 静态托管 + GET/PUT /api/data
├── public/index.html      # 单页 UI（无前端框架）
├── data/
│   ├── data.json          # 运行时唯一数据源
│   └── data.example.json  # 空数据模板
├── scripts/backup.sh      # 数据备份脚本
└── package.json
```

- **运行时**：Node.js（无需安装额外 npm 依赖）
- **存储**：单个 JSON 文件
- **接口**：
  - `GET /api/data` 读取账本（不含密码哈希）
  - `PUT /api/data` 写回账本（请求头 `X-Savings-Password` 校验）
  - `POST /api/password` 修改密码（需旧密码）

## 快速开始

### 环境要求

- Node.js 18+（本机已验证可用）

### 启动服务

```bash
cd /path/to/savings
npm start
# 或：node server.js
```

默认监听 `0.0.0.0:3000`：

| 访问方式 | 地址 |
|----------|------|
| 本机 | http://localhost:3000 |
| 局域网其他设备 | http://&lt;本机局域网IP&gt;:3000 |

查看本机 IP（macOS Wi‑Fi 常见）：

```bash
ipconfig getifaddr en0
```

自定义端口：

```bash
PORT=3456 npm start
```

> 服务需保持运行，其他设备才能访问并写回本机数据。

## 数据说明

### 主要字段

| 字段 | 说明 |
|------|------|
| `jars` | 三罐当前金额 |
| `logs` | 每次加减的操作日志 |
| `weeklyRecords` | 周结算快照 |
| `weeklySettleFrom` | 可选；早于此时间的结算点会跳过（用于「从某周日开始累计」） |
| `achievements` | 预留荣誉/奖章 |
| `passwordHash` | 修改密码的 SHA-256 哈希（GET 接口不会返回） |

首次启动若缺少 `data/data.json`，服务会自动创建空数据。也可参考 `data/data.example.json`。

### 密码

- 初始密码：`family`（首次运行或旧数据无哈希时自动写入）
- 改金额：弹出验证；密码错误时对话框不关闭，可多次重试；成功后再继续改金额
- **当前浏览器标签页**验证通过后会记住，关标签页后需再输
- 修改密码：右上角「修改密码」，先验证旧密码，新密码至少 4 位
- 密码不以明文存盘，只存哈希；备份到 GitHub 时也不会出现明文密码

### 分层规则

- 每层容量：`100` 元
- 层号与水位：`金额 % 100` 映射为当前层进度
- 总额数字始终显示真实金额

### 周结算

- 触发：每周日 20:00（`Asia/Shanghai`）；打开/切回页面时补算
- **超级变动（比上周）** = 本周超级 − 上周超级
- **总额** = 消费 + 爱心 + 超级
- **总变动（比上周）** = 本周总额 − 上周总额
- 首周无上周数据时，变动列显示 `—`

## 储蓄政策（摘要）

1. **大额奖励**：一次性存入超过 100 元，可获 10% 一次性奖励  
2. **月累计奖励**：月储蓄累计超过 200 元，可获 10% 一次性奖励（大额除外）  
3. **超级存钱罐周结福利**：按增长金额 1:1 补贴（大额资金除外）  

页面右上角「储蓄政策」可查看完整说明。

## 备份到 GitHub

仓库建议保持 **private**（含个人账目）。

```bash
# 仅提交 data.json（有改动时）并 push；无数据改动时也会推送未同步提交
npm run backup
```

或手动：

```bash
git add data/data.json
git commit -m "backup: 更新储蓄数据"
git push
```

## 常见注意

1. **本机服务要开着**，手机/其他电脑才能访问同一份账
2. 局域网下密码走 HTTP 请求头，只防误改，不是高安全场景
3. 多设备**同时**改同一笔账，仍可能后写覆盖先写；日常低频使用下，写前同步已显著降低风险
4. 不要把含真实账目的仓库改成公开仓库
